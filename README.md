# SSBM — Tagtsukamu

スマッシュブラザーズDXのマスターハンド／クレイジーハンドの未使用連携技
`Tagtsukamu` を、CPUが使用するようにするための調査・改造プロジェクトです。

- 対象：US版 1.00
- 実行環境：Dolphin
- 現状：公開解析コードによる予備調査。1.00用パッチは未作成・未検証。

判明した処理と未確認事項は [調査メモ](docs/research.md) を参照してください。

次の作業には、参考動画のURLと、対象のUS版1.00から抽出した `main.dol` が必要です。
Dolphinのゲームのプロパティ → ファイルシステム → ディスクの右クリック →
システムデータの抽出（Extract System Data）で取得できます。
`boot.bin` もあればディスクID・リビジョンを照合できます。

抽出データはローカルの `private/` に置き、GitHubへは追加しないでください。

完成時には、1.00向けのパッチまたはDolphin用コードと導入・検証手順を管理します。
