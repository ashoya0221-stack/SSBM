# SSBM — Tagtsukamu

スマッシュブラザーズDXのマスターハンド／クレイジーハンドの未使用連携技
`Tagtsukamu` を、CPUが使用するようにするための調査・改造プロジェクトです。

- 対象：US版 1.00
- 実行環境：Dolphin 5.0-21460（ユーザー指定）
- 参考動画：[ユーザー指定のYouTube動画](https://www.youtube.com/watch?v=do8EdYx5OaE)
- 現状：提供された `main.dol` の静的解析まで完了。パッチは未作成・未検証。

判明した処理と未確認事項は [予備調査](docs/research.md) と
[提供された1.00実行ファイルの解析](docs/us-1.00-analysis.md) を参照してください。

`main.dol` と動画のURLは受領済みです。
次は技名・モーション設定・掴み判定の対応を確認するため、同じディスクの
`PlMh.dat` と `PlCh.dat` が必要です。
Dolphinのゲームのプロパティ → ファイルシステムから各ファイルを抽出できます。
動画の再生・説明文の取得はこの環境ではアクセス制限により未確認です。

抽出データはローカルの `private/` に置き、GitHubへは追加しないでください。

## 実行ファイルの照合

Python 3.10以降で、提供された実行ファイルと調査プロファイルを照合できます。
ファイルは読み取りのみです。ゲームの動作テストやチート生成は行いません。

```sh
python tools/inspect_dol.py private/main.dol
python -m unittest discover -s tests -v
```

SHA-256が異なるファイルは照合を停止します。これは対象違いのアドレスを使わないための
検査であり、未改造の市販ディスクであることを認定するものではありません。

完成時には、1.00向けのパッチまたはDolphin用コードと導入・検証手順を管理します。
