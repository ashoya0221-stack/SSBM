# Dolphin 5.0-21460での導入と確認

対象は提供されたUS版1.00の実行ファイルです。ゲーム自体のバージョンは1.00を使用します。

## 導入

1. ゲームを停止する。
2. Dolphinの「設定」で「チートを有効にする」を有効にする。
3. ゲーム一覧でスマブラDXを右クリックし、「プロパティ」→「Geckoコード」を開く。
4. 前版のTagtsukamuコードのチェックを外し、「コード追加」で `Tagtsukamu v2 US1.00` 等の名前を付ける。
5. まず `dist/Tagtsukamu-US-1.00-combo-test.txt` の全内容をコード欄に貼り付ける。
6. 追加したコードにチェックを入れ、**ステートセーブを読み込まず、タイトルから起動する**。

前版のステートセーブには旧コードを指すコールバックが残るため、v2への切り替えには使えません。
提供されたDATやAJをゲーム内で差し替える操作は不要です。

通常版と確認版は同じ箇所を書き換えるため、**有効にするのはどちらか1つ**です。
切り替えるときもゲームを停止してから行ってください。実行中に設定した
コールバックが残るため、途中でコードを切り替える使い方には対応していません。

## どの場面で発動するか

両手が生存し、クレイジーハンドのCPUが連携技のグループを選んだときに発動します。
マスターハンドは現在の行動を終え、所定位置へ移動してから連携します。

- 確認版：連携技グループで毎回Tagtsukamuを選択する。
- 通常版：連携技グループの4候補のうち1つとして選択する。

確認版も、すべての通常攻撃をTagtsukamuへ置き換えるコードではありません。
両手がいるボス戦等で、連携技が選ばれるまで待ちます。

## 2人拘束の確認

二人同時の確認には、動画のように「両手＋掴まれる相手2人」がいる対戦設定を使用します。
各手がそれぞれ別の相手を掴むと、最大2人を同時に拘束します。
クラシックの相手がプレイヤー1人だけの場面では、2人を同時に拘束することはありません。

このコードは技の復元用です。二人の対戦相手を配置するには、既存のデバッグ対戦等の
設定が必要です。キャラクターを追加するコードは含めていません。

## 確認する動作

- 両手が所定位置へ移動し、同時に掴みを開始する。
- それぞれ別の相手を掴める。同じ相手の拘束を奪わない。
- 両手が同じモーションを進め、5回の握りと投げを同時に実行する。
- 一方だけが掴んだ場合も、両手が同じモーションを続け、成功した側を投げる。
- 掴み・握り・投げの効果音と、握り開始時の笑い声が鳴る。
- 両方が空振りすると、失敗モーションから通常行動へ戻る。
- 片手が倒れた場合、もう片方は自分が拘束している相手を解放する。

実行ファイル・DAT・AJの照合、生成したPowerPC命令、およびDOLのコマンド読み取り処理の
検証を実施済みです。**Dolphin上での修正版は未検証**なので、最初は確認版で
動きを確認してください。比較するときは、技の開始から投げ終わりまでの録画と、
使用したコードが通常版か確認版かを残すと調整しやすくなります。

## コード容量

v2通常版は3024バイト、確認版は3000バイトです。Dolphinの既定コード領域に収まりますが、
ほかのGeckoコードも同じ領域を使います。Dolphinがコード容量超過を表示した場合は、
確認に不要なGeckoコードを無効にしてください。
