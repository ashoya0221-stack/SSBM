# 3P・4Pでの手動操作：v4コア＋通常プレイヤー枠

US 1.00 / Dolphin 5.0-21460向けの手動操作テスト版です。
技本体と投げタイミングはCPU用v4を基準にし、通常Versusのプレイヤー枠検索をP3/P4へ切り替えています。人間操作側の連携要求値はUS版1.00の実行ファイルで確認した380をそのまま使います（383ではありません）。

## 前提設定

- 通常の大乱闘（Versus）を使用する。デバッグモードは不要。
- 3Pをマスターハンド、4Pをクレイジーハンドに割り当て、両方Human操作にする。
- 1P・2Pを同じチーム、3P・4Pの両手を反対チームにする。
- Dolphinのコントローラーポート3・4に、それぞれ3P・4Pの入力を割り当てる。
- Tagtsukamuコードはこの手動版だけを有効にする。CPU用v4や旧手動版、v7/v8を同時に有効にしない。

## 発動操作

1. **4P クレイジーハンド：Y＋十字キー左。** CHが所定位置へ移動して待機します。
2. CHが待機したら、**3P マスターハンド：Y＋十字キー上。** MHが移動し、両手のTagtsukamuを開始します。

4Pの入力だけで自動開始するv6/v7/v8方式ではありません。まずCHを動かし、次にMH側の入力を行う二段階方式です。

## 交換手順

ゲームを完全に停止してから旧Tagtsukamuコードを無効にし、このテスト版のコード全体へ入れ替えてください。
旧ステートセーブを読み込まず、タイトルから新しく起動してください。
